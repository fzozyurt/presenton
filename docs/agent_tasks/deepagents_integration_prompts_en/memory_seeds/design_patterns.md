# Reusable Design Patterns

## General

- Use strong title hierarchy.
- Avoid crowded slides.
- Prefer concise slide titles that state the insight.
- Use charts only when numeric data supports them.
- Keep slide rhythm varied across the deck.

## Gamma-like Quality Rules

- One dominant visual or message per slide.
- Avoid generic stock visuals when they do not add meaning.
- Use spacing generously.
- Use visual contrast to guide attention.
- Prefer simple, readable layouts over decorative complexity.

## Layout Lessons

- Data slides should use chart/table layouts only when real data exists.
- Process slides should use timeline, step, or flow layouts.
- Comparison slides should use side-by-side or matrix layouts.
- Recommendation slides should use clear hierarchy and minimal supporting text.
